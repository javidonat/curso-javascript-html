Modificar estilos CSS

Con la propiedad style de un elemento podemos cambiar sus estilos CSS desde JavaScript. Las propiedades compuestas se escriben en camelCase: background-color pasa a ser backgroundColor.

Ejemplo: modificar los estilos de una caja

Esta es la caja cuyos estilos vamos a modificar.
// Guardamos la caja en una variable para usarla después
const caja = document.getElementById("caja");

// Botón 1: cambia el color del texto y el color de fondo
document.getElementById("btnColores").addEventListener("click", function () {
  caja.style.color = "#ffffff";            // color del texto
  caja.style.backgroundColor = "#1e3c72";  // background-color en camelCase
});

// Botón 2: aumenta el tamaño de la letra en 4 píxeles
let tamano = 16;
document.getElementById("btnTamano").addEventListener("click", function () {
  tamano = tamano + 4;
  caja.style.fontSize = tamano + "px";     // hay que añadir la unidad
});

// Botón 3: oculta o muestra la caja
let visible = true;
document.getElementById("btnOcultar").addEventListener("click", function () {
  visible = !visible;                      // invierte el valor true/false
  caja.style.opacity = visible ? "1" : "0.2";
});

// Botón 4: elimina todos los estilos aplicados con JavaScript
document.getElementById("btnRestaurar").addEventListener("click", function () {
  caja.style.cssText = "";
  tamano = 16;
  visible = true;
});

Explicación

  • caja.style.color y caja.style.backgroundColor modifican los estilos en línea del elemento.
  • Los valores con unidades, como el tamaño de letra, se escriben como texto: "20px".
  • visible ? "1" : "0.2" es el operador ternario: si visible es verdadero usa "1", y si no, "0.2".
  • style.cssText = "" borra todos los estilos en línea y la caja vuelve a su aspecto original.
