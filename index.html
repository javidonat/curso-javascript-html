Bienvenido al curso

En este curso aprenderás a utilizar JavaScript para interactuar con los elementos de una página web. A través de ejemplos prácticos y comentados verás cómo modificar el contenido HTML, cambiar los estilos CSS y manipular los atributos de los elementos desde el código.

Cada sección incluye un ejemplo funcional junto con la explicación de su código, para que puedas probarlo y entender qué ocurre en cada paso.
