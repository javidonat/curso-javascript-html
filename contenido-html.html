Modificar contenido HTML

La propiedad innerHTML permite leer y cambiar el contenido HTML que hay dentro de un elemento desde JavaScript.

Ejemplo 1: cambiar el contenido de un párrafo

Este es el texto original del párrafo.

const texto = document.getElementById("texto");
const textoOriginal = texto.innerHTML;

document.getElementById("btnCambiar").addEventListener("click", function () {
  texto.innerHTML = "<strong>¡Contenido modificado!</strong> Ahora hay <em>etiquetas HTML</em> nuevas.";
});

document.getElementById("btnRestaurar").addEventListener("click", function () {
  texto.innerHTML = textoOriginal;
});

Explicación

  • document.getElementById("texto") busca en la página el elemento con id="texto" y lo guarda en una variable.
  • texto.innerHTML devuelve el HTML que hay dentro del párrafo. Lo guardamos en textoOriginal para poder restaurarlo.
  • addEventListener("click", ...) ejecuta la función cuando el usuario pulsa el botón.
  • Al asignar un valor a texto.innerHTML, el contenido del párrafo se reemplaza y el navegador interpreta las etiquetas HTML nuevas.

Ejemplo 2: añadir elementos a una lista

    const lista = document.getElementById("lista");
let contador = 1;

document.getElementById("btnAnadir").addEventListener("click", function () {
  lista.innerHTML += "<li>Elemento número " + contador + "</li>";
  contador++;
});

    Explicación

    • El operador += añade HTML nuevo al contenido que ya había, en lugar de reemplazarlo.
    • La variable contador aumenta en cada clic para numerar los elementos.
