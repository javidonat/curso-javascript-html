Modificar atributos HTML

Los atributos (href, src, disabled, placeholder...) se pueden leer y cambiar desde JavaScript con getAttribute, setAttribute y removeAttribute.

Ejemplo 1: cambiar el destino de un enlace

Este enlace lleva al Home

const enlace = document.getElementById("enlace");

document.getElementById("btnEnlace").addEventListener("click", function () {
  // Cambia a dónde apunta el enlace
  enlace.setAttribute("href", "https://developer.mozilla.org/es/");
  // Hace que se abra en una pestaña nueva
  enlace.setAttribute("target", "_blank");
  // Cambia el texto visible del enlace
  enlace.textContent = "Ahora voy a MDN (pestaña nueva)";
});

Explicación

  • setAttribute("href", valor) cambia el atributo href, es decir, el destino del enlace.
  • setAttribute("target", "_blank") crea el atributo target, que no existía, y hace que el enlace abra una pestaña nueva.
  • textContent cambia solo el texto que se ve, sin tocar los atributos.

Ejemplo 2: habilitar y deshabilitar un campo

const campo = document.getElementById("campo");

document.getElementById("btnDeshabilitar").addEventListener("click", function () {
  // Un atributo booleano solo necesita existir, por eso el valor es ""
  campo.setAttribute("disabled", "");
  campo.setAttribute("placeholder", "Campo deshabilitado");
});

document.getElementById("btnHabilitar").addEventListener("click", function () {
  // removeAttribute elimina el atributo por completo
  campo.removeAttribute("disabled");
  campo.setAttribute("placeholder", "Escribe aquí");
  // getAttribute lee el valor actual de un atributo
  console.log(campo.getAttribute("placeholder"));
});

Explicación

  • disabled es un atributo booleano: si está presente, el campo queda bloqueado.
  • removeAttribute("disabled") lo elimina y el campo vuelve a poder usarse.
  • getAttribute("placeholder") devuelve el valor del atributo; aquí se muestra en la consola del navegador (F12).
